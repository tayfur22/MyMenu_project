# MyMenu Project - Restaurant Menu Management System

This project is a backend API for a restaurant menu management system built using Java Spring Boot.

---

## Features:
- Manage restaurants, menus, and dishes
- User roles and authentication
- CRUD operations for menu items
- Rating and review system

---

## Technologies Used:
- Java 23
- Spring Boot
- Spring Security
- PostgreSQL
- Maven
